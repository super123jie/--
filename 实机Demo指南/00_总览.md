# HomeCare-Agent 实机 Demo 总览

> 中兴捧月 · 兴享智家 · 团队：南邮upup（南京邮电大学）
> 实机版本：树莓派 5 (4GB) + GPIO 外设
> 文档版本：V1 · 2026-04-27

---

## 这是什么？

把你已经写好的、跑在 Windows 上的"软件智能家居 Agent"搬到 **真实硬件** 上：
- **大脑**：树莓派 5（一块 ¥600 的迷你电脑，运行 Linux）
- **手脚**：用便宜外设（LED 灯带、小风扇、SG90 舵机、继电器、蜂鸣器）模拟智能家居
- **感官**：温湿度 / 燃气 / 人体三类传感器，让系统能"感知"环境
- **效果**：当你对着麦克风说"我要睡觉了"，**真的灯会渐暗、舵机转动模拟拉窗帘、风扇打开模拟空调、继电器响一声模拟锁门**

这能直接把比赛"演示（20 分）"维度从仿真档（12-14 分）拉到实机档（18-20 分）。

## 风险与对策

| 风险 | 应对 |
| --- | --- |
| 树莓派从快递到货时间 > 3 天 | 立刻下单 + 优先选 24 小时发货商家；Day 1 下完单别等，继续在 Windows 写 PDF |
| 接线接错烧坏元器件 | 严格按 [03_接线图.md](03_接线图.md) 颜色编码；先用 5V 元件，避开 3.3V 引脚误接 |
| Pi 上 PyTorch 安装慢 | 用清华镜像源；预先在 [02 部署手册](02_树莓派系统部署手册.md) 写明命令 |
| 麦克风识别不准 | 先用键盘输入（Streamlit 文本框）作为兜底，不强依赖语音 |
| Demo 录视频出 bug | Day 5 上午预留充足时间；视频可以剪辑，不需一镜到底 |
| 评委要求现场演示但 Pi 在家 | 把树莓派 + 面包板放在透明亚克力盒里方便携带 |
