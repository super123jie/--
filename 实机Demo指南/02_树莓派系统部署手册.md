# 02 · 树莓派系统部署手册

> **硬件到货当晚执行**。预计耗时 2 小时（其中等待装机/下载时间约 1 小时，可同步刷手机）。

---

## 一、准备工作（在 Windows 笔记本上）

### 1.1 下载 3 个软件

| 软件 | 用途 | 下载地址 |
| --- | --- | --- |
| Raspberry Pi Imager | 烧录 SD 卡 | https://www.raspberrypi.com/software/ |
| WinSCP | Windows ↔ Pi 文件互传 | https://winscp.net/ |
| PuTTY | SSH 终端（Win 11 已内置 ssh 命令也可） | https://www.putty.org/ |

> 国内下载慢可去 [清华镜像](https://mirrors.tuna.tsinghua.edu.cn/raspberry-pi-os-images/) 找 ISO，但建议直接用 Imager 自动下载。

### 1.2 准备好 WiFi 信息

记下你家/宿舍的：
- WiFi SSID（名字）
- WiFi 密码
- 路由器后台地址（一般 `192.168.1.1` 或 `192.168.0.1`）— 后面要看 Pi 拿到什么 IP

---

## 二、Step 1：烧录系统到 SD 卡（15 分钟）

### 2.1 把 SD 卡插进读卡器，读卡器插电脑

### 2.2 打开 Raspberry Pi Imager

1. 点 **CHOOSE DEVICE** → 选 **Raspberry Pi 5**
2. 点 **CHOOSE OS** → **Raspberry Pi OS (64-bit)**（带桌面版本）
   - ⚠️ 必须 64-bit。32-bit 跑不动 PyTorch
3. 点 **CHOOSE STORAGE** → 选你的 SD 卡（**确认容量是 64GB，别选错盘**）
4. 点 **NEXT** → 弹出"Use OS customisation?"对话框，**选 EDIT SETTINGS**

### 2.3 OS 自定义（关键，提前配置好免去后面麻烦）

**General 标签**：
- ✅ Set hostname：填 `homecare-pi`
- ✅ Set username and password：用户名 `pi`，密码自定义（**记住，后面要用**）
- ✅ Configure wireless LAN：填 SSID 和密码，国家选 **CN**
- ✅ Set locale settings：时区 `Asia/Shanghai`，键盘 `us`

**Services 标签**：
- ✅ Enable SSH：选 **Use password authentication**

点 **SAVE** → 回到主界面 → 点 **YES** 开始烧录 → 等 5-10 分钟（写入 + 验证）

### 2.4 烧录完成后

- Imager 会提示"You can now remove the SD card"
- 拔出读卡器，把 SD 卡插进树莓派背面的卡槽（金属面朝主板方向）

---

## 三、Step 2：树莓派首次启动（15 分钟）

### 3.1 接线

1. 把 SD 卡插好
2. 接散热壳/风扇（按散热壳说明书装）
3. **先不要接外设**（面包板、灯带等都先不接）
4. 接显示器（HDMI to micro-HDMI）— 可选，没显示器也能 SSH
5. 接 USB 键盘 — 可选
6. **最后**接电源（27W USB-C），看到红绿 LED 亮起

### 3.2 Pi 启动后做的事

**有显示器**：等待自动进桌面（首次开机约 2 分钟），不需要做配置（已在烧录时自定义）

**无显示器（headless）**：
1. 等 1 分钟让 Pi 联网
2. 在路由器后台找到 `homecare-pi` 对应的 IP（一般是 `192.168.x.x`）
3. 也可在 Windows cmd 跑 `ping homecare-pi.local` 看 IP

### 3.3 SSH 连接

在 Windows PowerShell 或 cmd：
```bash
ssh pi@homecare-pi.local
# 或用 IP
ssh pi@192.168.1.123
```
首次会问 `yes/no`，输 `yes`。然后输你设的密码。

看到提示符 `pi@homecare-pi:~ $` 即成功。

---

## 四、Step 3：系统升级 + 启用接口（20 分钟）

### 4.1 升级系统包

```bash
sudo apt update
sudo apt full-upgrade -y
sudo apt install -y \
    git wget curl vim htop \
    python3-pip python3-venv python3-dev \
    python3-rpi.gpio python3-gpiozero \
    i2c-tools libgpiod-dev \
    portaudio19-dev libatlas-base-dev \
    ffmpeg
```

> 国内慢的话先换源（清华镜像）：
> ```bash
> sudo nano /etc/apt/sources.list
> # 把 deb 行改成：
> # deb https://mirrors.tuna.tsinghua.edu.cn/raspbian/raspbian/ bookworm main contrib non-free rpi
> ```
> 然后再跑上面的 apt update。

### 4.2 启用 GPIO/I2C/SPI/Serial

```bash
sudo raspi-config
```

在 TUI 菜单里：
1. `3 Interface Options` → `I5 I2C` → Yes
2. `3 Interface Options` → `I4 SPI` → Yes
3. `3 Interface Options` → `I6 Serial Port` → 关闭 login shell, 启用 serial hardware
4. `Finish` → 选 reboot

重启后再次 SSH 进入。

### 4.3 验证

```bash
# 检查 GPIO
gpio readall  # （Pi 5 上可能未安装，下面命令更通用）
ls /sys/class/gpio
# 检查 I2C
sudo i2cdetect -y 1
# 应该看到 8x8 表格，目前都是 -- （没接设备）
```

## 五、Step 4：把项目从 Windows 搬到 Pi（30 分钟）

### 5.1 在 Windows 上压缩项目（不带 venv）

PowerShell：
```powershell
cd E:\1\中兴
Compress-Archive -Path "南邮upup-南京邮电大学" -DestinationPath "homecare.zip" -Force
# 或者用右键 → 7-Zip 压缩
```

注意：venv 文件夹**不要打包**（Linux 跟 Windows 的虚拟环境不通用），其它都打包。

### 5.2 用 WinSCP 或 SCP 传到 Pi

**WinSCP 图形化**：
1. 打开 WinSCP，新建 Site：协议 SFTP，主机 `homecare-pi.local`，用户名 `pi`，密码刚才设的
2. 连上后，左边 Windows、右边 Pi 的 `/home/pi/`
3. 把 `homecare.zip` 拖到右边

**或命令行 SCP**：
```bash
# 在 Windows PowerShell
scp E:\1\中兴\homecare.zip pi@homecare-pi.local:/home/pi/
```

### 5.3 在 Pi 上解压

```bash
cd ~
unzip homecare.zip
mv "南邮upup-南京邮电大学" homecare
ls homecare/algorithm/
# 应该看到 main.py / src / tests / models 等
```

### 5.4 创建 Pi 上的虚拟环境并装依赖

```bash
cd ~/homecare
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
# 国内换源
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
# 装依赖（PyTorch 自动适配 ARM64，约 200MB，耐心等）
pip install -r algorithm/requirements.txt
# 多装 4 个 GPIO 相关库
pip install RPi.GPIO gpiozero adafruit-circuitpython-dht rpi_ws281x
```

> 大约 5-15 分钟（看网速）。如果 PyTorch 装失败：
> ```bash
> pip install torch --index-url https://download.pytorch.org/whl/cpu
> ```

### 5.5 验证软件可跑

```bash
cd ~/homecare
source venv/bin/activate
PYTHONIOENCODING=utf-8 python algorithm/main.py
```

应看到 5 条演示输出（睡觉/确认/调温/摔倒/状态查询）。看到 JSON 即成功。

## 六、Step 5：跑测试集（验证移植没出问题，15 分钟）

```bash
cd ~/homecare
source venv/bin/activate

# 内部 68 条
python algorithm/tests/run_test.py
# 期望：100%；P95 延迟 30-60 ms（Pi 比笔记本慢 2-3 倍但仍达标）

# 外部 100 条
python algorithm/tests/run_external_test.py
# 期望：100%
```

如果两个测试都 100%，说明软件移植成功，跟 Windows 上结果一致。

## 七、Step 6：跑 Streamlit Demo（验证浏览器能访问，10 分钟）

```bash
cd ~/homecare
source venv/bin/activate
streamlit run algorithm/src/demo.py --server.address 0.0.0.0
```

注意 `--server.address 0.0.0.0` 让局域网内任何设备都能访问。

启动后看到：
```
Local URL: http://localhost:8501
Network URL: http://192.168.1.xxx:8501
```

**在 Windows 笔记本浏览器打开 `Network URL`** —— 应看到熟悉的 HomeCare-Agent 界面。

按 Ctrl+C 停止。

## 八、常见问题

### Q1：SSH 提示 "connection refused"
- Pi 还没启动完，等 1-2 分钟再试
- 没启用 SSH：把 SD 卡插回 Windows，在 boot 分区根目录建一个空文件 `ssh`（无后缀）

### Q2：apt 装包失败 "Could not connect"
- 网络问题或源不通；换清华镜像（见 4.1 注释）

### Q3：`pip install` 卡在 PyTorch
- 用清华源 + CPU 版：`pip install torch --index-url https://pypi.tuna.tsinghua.edu.cn/simple`

### Q4：跑 `streamlit run` 报错 `[Errno 99] Cannot assign requested address`
- 改成 `--server.address 0.0.0.0`，不要写 IP

### Q5：模型加载失败 "Model not found"
- `models/embedder/` 目录可能没传过来。在 Windows 检查这个目录是否在 zip 里
- 或在 Pi 上重新下载：`python algorithm/scripts/download_model.py`（首次需联网，~92MB）

### Q6：内存不够 OOM
- Pi 5 4GB 模型 + Streamlit + Python 占约 1.5GB，有富余
- 如果还报 OOM，可能 swap 没启用：`sudo dphys-swapfile setup` 然后 `sudo dphys-swapfile swapon`
