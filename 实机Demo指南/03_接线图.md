# 03 · 接线图

> **接线前必读完一遍**。预计耗时 1.5 小时。
> 接错可能烧元件，**严格按颜色和引脚号操作**。

---

## 一、Pi 5 GPIO 引脚总图（先认识一下）

Pi 5 跟 Pi 4 的 40 针 GPIO 完全兼容。引脚编号有两种说法：
- **物理编号**（Pin#）：1-40，板上从左上角数
- **BCM 编号**（GPIO#）：芯片内部编号，**Python 代码里用这个**

```
            Pin1 [3.3V] [5V] Pin2
              3 [GPIO2] [5V] 4
              5 [GPIO3] [GND] 6
              7 [GPIO4] [GPIO14] 8
              9 [GND]  [GPIO15] 10
             11 [GPIO17][GPIO18] 12
             13 [GPIO27][GND] 14
             15 [GPIO22][GPIO23] 16
             17 [3.3V] [GPIO24] 18
             19 [GPIO10][GND] 20
             21 [GPIO9] [GPIO25] 22
             23 [GPIO11][GPIO8] 24
             25 [GND]  [GPIO7] 26
             27 [GPIO0][GPIO1] 28
             29 [GPIO5][GND] 30
             31 [GPIO6][GPIO12] 32
             33 [GPIO13][GND] 34
             35 [GPIO19][GPIO16] 36
             37 [GPIO26][GPIO20] 38
             39 [GND] [GPIO21] 40
```

**关键提醒**：
- **3.3V 和 5V 不能混！** 只有 5V 引脚（Pin 2/4）能驱动灯带、继电器、舵机；3.3V（Pin 1/17）只能给传感器逻辑电平
- **GND（地）**多个，任意一个都行
- 杜邦线母头插 Pi GPIO 排针，公头插面包板

## 二、本项目引脚分配总表（背下来）

| BCM | 物理 Pin | 用途 | 元件 | 杜邦线颜色（建议） |
| --- | --- | --- | --- | --- |
| **5V** | Pin 2 | 电源正极 | → 面包板正电源轨 | 红 |
| **GND** | Pin 6 | 接地 | → 面包板地轨 | 黑 |
| GPIO18 | Pin 12 | PWM | WS2812 灯带 DIN | 橙 |
| GPIO12 | Pin 32 | PWM | 5V 风扇（空调）调速 | 黄 |
| GPIO13 | Pin 33 | PWM | SG90 舵机 1（窗帘） | 蓝 |
| GPIO19 | Pin 35 | PWM | SG90 舵机 2（门） | 蓝 |
| GPIO5 | Pin 29 | OUT | 继电器 1（门锁） | 绿 |
| GPIO6 | Pin 31 | OUT | 继电器 2（燃气阀） | 绿 |
| GPIO16 | Pin 36 | OUT | 继电器 3（电视） | 绿 |
| GPIO20 | Pin 38 | OUT | 继电器 4（净化器/备用风扇） | 绿 |
| GPIO21 | Pin 40 | OUT | 蜂鸣器 | 紫 |
| GPIO4 | Pin 7 | IN | DHT22 数据 | 灰 |
| GPIO17 | Pin 11 | IN | MQ-2 数字输出 DO | 灰 |
| GPIO27 | Pin 13 | IN | PIR 输出 | 灰 |
| 3.3V | Pin 1 | 传感器 VCC | → 传感器正电源 | 红（细） |

> 颜色不强制，但**统一颜色编码大幅降低接错概率**。建议第一次接的时候照着颜色严格执行。

## 三、面包板布局

```
       ╔══════════════════════════════════╗
       ║  +  -    a b c d e | f g h i j +  - ║
       ║                  ←breadboard→        ║
       ╠══════════════════════════════════╣
红轨   ║ +5V (从 Pi Pin2)                  ║
黑轨   ║ GND (从 Pi Pin6)                  ║
       ║                                    ║
       ║ 区域 1：WS2812 灯带（左上）        ║
       ║ 区域 2：4 路继电器（左下）         ║
       ║ 区域 3：2 个 SG90 舵机（中）       ║
       ║ 区域 4：风扇 + 蜂鸣器（右上）      ║
       ║ 区域 5：3 个传感器（右下）         ║
       ╚══════════════════════════════════╝
```

**第一步**：用红、黑两根杜邦线把 Pi Pin2(5V)、Pin6(GND) 接到面包板的红、黑总线轨。
所有元件都从总线轨取电。

## 四、逐元件接线（按下面顺序接）

### 元件 1：WS2812 LED 灯带

灯带有 3 根线（注意接口，有的是 4 针 DIN/DOUT）：

| 灯带线 | 接哪 | 颜色 |
| --- | --- | --- |
| VCC（红/+5V） | 面包板 5V 总线轨 | 红 |
| GND（黑/-） | 面包板 GND 总线轨 | 黑 |
| DIN（绿/数据） | Pi GPIO18（Pin 12） | 橙 |

**注意**：灯带 60 灯瞬时电流可达 3.6A，**别从 Pi 直接供电**！必须用 Pi 5V 引脚（Pi 5 电源稍强）；如灯带亮度调高时 Pi 重启，说明电流不够，需外接 5V 充电器给灯带单独供电（共地即可）。

接完先用万用表量一下：5V 总线轨电压在 4.8-5.2V 即正常。

### 元件 2：4 通道继电器模块

继电器模块有 6 个引脚：

| 引脚 | 接哪 |
| --- | --- |
| VCC | 面包板 5V 总线轨 |
| GND | 面包板 GND 总线轨 |
| IN1 | GPIO5（Pin 29） |
| IN2 | GPIO6（Pin 31） |
| IN3 | GPIO16（Pin 36） |
| IN4 | GPIO20（Pin 38） |

**继电器输出端**（COM/NO/NC）暂时不接负载，只用 LED 指示灯就能看到吸合。
后续如要驱动 220V 大功率设备**别自己接 220V**（危险），用 LED + 限流电阻代替演示即可。

### 元件 3：SG90 舵机 × 2

每个舵机 3 根线：

| 舵机线 | 接哪 |
| --- | --- |
| VCC（红） | 面包板 5V 总线轨 |
| GND（棕/黑） | 面包板 GND 总线轨 |
| 信号（橙/黄） | 舵机 1 → GPIO13（Pin 33）；舵机 2 → GPIO19（Pin 35） |

**注意**：单个 SG90 启动瞬时电流 500-700mA，2 个并联 1.4A 起步，Pi 5V 应付得来但不要再加更多舵机。

### 元件 4：5V 风扇（模拟空调出风）

风扇通常 2 线（红+黑）。**因为要 PWM 调速**，需要中间加一个 NPN 三极管驱动（学习套件里一般有 S8050 或 PN2222）。

简化版（**直接开关、不 PWM**）：把红线接到继电器 4 的常开端，常闭端接 5V，通过继电器开关控制。

完整 PWM 版：
- 风扇红 → 5V 总线
- 风扇黑 → 三极管 C 极
- 三极管 E 极 → GND
- 三极管 B 极 → 1KΩ 电阻 → GPIO12（Pin 32）

> 第一次做时强烈建议**简化版**（继电器开关），跳过三极管，等其它都 OK 了再回头优化。

### 元件 5：蜂鸣器

5V 有源蜂鸣器 2 引脚：

| 引脚 | 接哪 |
| --- | --- |
| VCC（+） | GPIO21（Pin 40） |
| GND（-） | 面包板 GND 总线轨 |

> 直接用 GPIO 高电平驱动即可，电流 < 30mA，不需要三极管。

### 元件 6：DHT22 温湿度传感器

模块版（4 脚，带板载电阻）：

| 引脚 | 接哪 |
| --- | --- |
| VCC | 面包板 3.3V 总线（**注意不是 5V**）|
| GND | 面包板 GND 总线 |
| DATA | GPIO4（Pin 7） |
| 第 4 脚 | 不接 / 或 NC |

**3.3V 总线怎么搭**：另起一根红线，从 Pi Pin1（3.3V）接到面包板**侧边一行**做 3.3V 子轨，所有传感器 VCC 都从这接。

### 元件 7：MQ-2 燃气传感器

模块 4 脚：

| 引脚 | 接哪 |
| --- | --- |
| VCC | 面包板 5V 总线 （**这个传感器要 5V**） |
| GND | 面包板 GND 总线 |
| DO（数字输出） | GPIO17（Pin 11） |
| AO（模拟输出） | 不接（需 ADC，Pi 没 ADC） |

**调阈值**：模块上有蓝色电位器，**逆时针旋几圈让灵敏度适中**。手指捏住模块测气体源（打火机别按按钮，只放气）几秒，DO 应该输出 LOW 触发。

### 元件 8：HC-SR501 PIR 人体感应

模块 3 脚：

| 引脚 | 接哪 |
| --- | --- |
| VCC | 面包板 5V 总线 |
| GND | 面包板 GND 总线 |
| OUT | GPIO27（Pin 13） |

**调灵敏度**：模块两个橙色电位器：
- 距离调节：右旋灵敏度高（最远 7m）
- 延时调节：左旋触发后保持时间短（5 秒）
- 跳线选 H 模式（重复触发）

## 五、ASCII 完整接线全景图

```
   Raspberry Pi 5                     面包板 / 元件
   ┌──────────────┐
   │              │
   │  Pin 2  (5V) ├───红───────────────► 5V 总线
   │  Pin 1 (3V3) ├───红───►3V3 子轨（仅 DHT22 等需要的）
   │  Pin 6 (GND) ├───黑───────────────► GND 总线
   │              │
   │  GPIO18(P12) ├───橙───►WS2812 DIN  (灯带)
   │  GPIO12(P32) ├───黄───►风扇驱动     (5V 风扇)
   │  GPIO13(P33) ├───蓝───►SG90#1 信号  (窗帘)
   │  GPIO19(P35) ├───蓝───►SG90#2 信号  (门)
   │              │
   │  GPIO5 (P29) ├───绿───►继电器1 IN   (门锁)
   │  GPIO6 (P31) ├───绿───►继电器2 IN   (燃气阀)
   │  GPIO16(P36) ├───绿───►继电器3 IN   (电视)
   │  GPIO20(P38) ├───绿───►继电器4 IN   (净化器/备用风扇)
   │              │
   │  GPIO21(P40) ├───紫───►蜂鸣器 +
   │              │
   │  GPIO4 (P7)  ├───灰───►DHT22 DATA
   │  GPIO17(P11) ├───灰───►MQ-2 DO
   │  GPIO27(P13) ├───灰───►PIR OUT
   └──────────────┘

  注：所有元件 VCC 接 5V 或 3.3V 总线（按上文）
       所有元件 GND 接 GND 总线
```

## 六、接线检查清单

接完后**通电前**逐项核对：

- [ ] 红线只接到 5V 或 3.3V，没接到信号脚
- [ ] 黑线全部接到 GND 总线
- [ ] DHT22 VCC 是 3.3V 不是 5V
- [ ] MQ-2 VCC 是 5V
- [ ] 杜邦线没虚接（轻拽不掉）
- [ ] 面包板上没有元件相互短接（金属脚没碰一起）
- [ ] 灯带 DIN 朝向正确（灯带上有箭头标识方向）
- [ ] 继电器 IN 端有 4 路全部接好

**完成检查 → 拔掉 Pi 电源插上 SD 卡 → 通电**。

观察现象：
- 灯带应该是熄灭状态（默认）
- 继电器板上 LED 全灭（4 个 IN 默认是高电平 = 不吸合，不同模块逻辑可能反向）
- 蜂鸣器无声
- 舵机无动作

如果通电就有元件冒烟/异响，立刻断电检查接线。
