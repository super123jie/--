## 四、逐个测试

> 注意：所有调试脚本都要在 Pi 上跑（不是 Windows），用 `python3` 启动。
> WS2812 灯带的脚本（test_01, test_99）**必须 sudo 跑**（PWM 需 root）。

### 测试 1：WS2812 LED 灯带

```bash
sudo python3 /home/pi/GPIO调试脚本/test_01_lights.py
```

**预期**：1 米 60 灯灯带依次亮红、绿、蓝、暖白各 1 秒，最后熄灭。

**常见问题**：
| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 完全不亮 | DIN 接错 | 确认 GPIO18 (Pin 12)，灯带箭头朝远离 Pi 的方向 |
| 闪一下就灭 | 电源不够 | 灯带需要单独 5V 电源，跟 Pi 共地即可 |
| 颜色乱（蓝色显示成绿色） | 颜色顺序不是 GRB | 在脚本里把 `Color(r,g,b)` 改顺序试试 |
| Permission denied | 没用 sudo | `sudo python3 test_01_lights.py` |

---

### 测试 2：4 路继电器

```bash
python3 /home/pi/GPIO调试脚本/test_02_relay.py
```

**预期**：依次听到 4 声"咔嗒"，板上 4 个 LED 依次点亮 1.5 秒。

**常见问题**：
| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 4 路同时吸合（一通电就全亮） | 触发逻辑反了 | 把脚本里 `ACTIVE_LOW = True` 改成 `False` |
| 完全不动 | VCC 没接 5V | 检查继电器 VCC 是接到 5V 总线 |
| Pi 重启 | 继电器吸合电流大 | 加一个 1000μF 电容跨在 5V-GND；或单独供电继电器 |

---

### 测试 3：SG90 舵机

```bash
python3 /home/pi/GPIO调试脚本/test_03_servo.py
```

**预期**：两个舵机依次扫角度 0° → 45° → 90° → 135° → 180° → 90° → 0°。

**常见问题**：
| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 舵机抖动不停 | PWM 信号不稳 | 信号脚接更短的杜邦线；舵机和 Pi 共 5V/GND |
| 转不到位（如只到 90°） | 工作电压不够 | SG90 需要 ≥ 4.8V，确认 5V 总线电压 |
| 不动 | GPIO 选错 | 信号脚必须接 GPIO13/19，不能用 GPIO5/6 等 |

---

### 测试 4：蜂鸣器 + 风扇

```bash
python3 /home/pi/GPIO调试脚本/test_04_buzzer_fan.py
```

**预期**：蜂鸣器响 3 短声，然后风扇启动 2.5 秒。

**常见问题**：
| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 蜂鸣器无声 | 是无源蜂鸣器 | 无源需 PWM 信号，建议买有源 5V 蜂鸣器换上 |
| 风扇不转 | 继电器没吸合 | 确认 test_02 通过；风扇红线接到继电器 NO 端 |
| 蜂鸣器一直响 | 极性反了 | 蜂鸣器 + 接 GPIO，- 接 GND，不能反 |

### 测试 5：传感器三件套

```bash
python3 /home/pi/GPIO调试脚本/test_05_sensors.py
```

**预期**：30 秒内每 2 秒打印一行：
```
[ 0s] 温度=24.8℃ 湿度=52.3%RH 燃气=正常 人体=无
[ 2s] 温度=24.9℃ 湿度=52.5%RH 燃气=正常 人体=无
...
```

**测试触发**：
- **DHT22**：用手指捂住模块 5 秒，温度应 +2-3℃
- **MQ-2**：打火机靠近模块（**不点火，只按住放气**）2 秒 → 应看到"⚠️触发"；模块上电位器逆时针旋几圈让灵敏度合适
- **PIR**：在模块前挥手 → 应看到"有人"；触发后会保持 5 秒（电位器调）

**常见问题**：
| 现象 | 原因 | 修复 |
| --- | --- | --- |
| DHT22 全报 None | 库未装 | `pip install adafruit-circuitpython-dht` |
| DHT22 偶尔 err 但有时正常 | DHT22 协议时序紧 | 接近些 + 重试，正常现象 |
| MQ-2 一直触发 | 灵敏度太高 | 顺时针旋蓝色电位器调低 |
| MQ-2 永远不触发 | 灵敏度太低 / 没预热 | MQ-2 通电需 30 秒预热；逆时针旋电位器 |
| PIR 一直触发 | 跳线不对 | 跳线选 H 模式（重复触发）|

### 测试 99：综合（睡眠模式动作链）

```bash
sudo python3 /home/pi/GPIO调试脚本/test_99_all.py
```

**预期**：依次执行
1. 灯带从亮 → 暗（暖白 15%）
2. 风扇启动（嗡嗡声）
3. 舵机转到 180°（拉窗帘动作）
4. 继电器 1 吸合（锁门"咔嗒"）

**意义**：这就是 Day 5 演示视频"我要睡觉了"对应的真实动作。如果这一步顺畅了，说明所有元件都能协同工作。

## 五、调试小技巧

### 5.1 实时监控 GPIO 状态

```bash
watch -n 0.5 'cat /sys/kernel/debug/gpio'
# 需要 sudo
sudo watch -n 0.5 'cat /sys/kernel/debug/gpio'
```

### 5.2 用 LED 临时替代任何元件

任何要测试 GPIO 输出的场景，都可以接一个 LED + 220Ω 电阻到 GND，用 LED 闪灭判断 GPIO 是不是真的在动。

### 5.3 万用表是你的好朋友

有问题先量电压：
- 5V 总线：4.8-5.2V 正常
- 3.3V 总线：3.2-3.4V 正常
- GPIO 输出 HIGH：≈ 3.3V
- GPIO 输出 LOW：≈ 0V

### 5.4 接错的常见信号

| 信号 | 含义 |
| --- | --- |
| Pi 上 PWR LED 转红色长亮（应该是绿色闪烁） | 电压不足，电源不够功率 |
| 一通电元件烫手 | 接反了，立刻断电 |
| Pi 启动慢 / 反复重启 | 大电流元件在拉低系统电压 |
| 杜邦线发烫 | 短路，立刻断电 |
