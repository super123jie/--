# 06 · 演示视频录制脚本（3 分钟）

> 评分细则：演示维度 20 分，"实机 Demo > 仿真算法 > 方案 idea"。
> 这一份脚本帮你拍出能拿满分的 3 分钟视频。

---

## 一、录制前的准备

### 1.1 设备清单

- 手机（横屏拍摄，1080p 60fps）+ 三脚架 / 桌面支架
- 充足光照（房间日光灯 + 一盏台灯打硬件）
- 安静环境（无背景音乐、空调、风扇噪音）
- 笔记本电脑（演示 Streamlit 界面）
- 树莓派系统（HDMI 接显示器或者 SSH 模式都可）
- 所有外设接好且通过 [04 调试](04_GPIO调试与单元测试.md)

### 1.2 场景布置

桌面布局（俯拍角度好）：

```
   ┌──────────────────────────────────────┐
   │ 笔记本（显示 Streamlit）             │ ← 镜头能看到屏幕
   │                                      │
   ├──────────────────────────────────────┤
   │ 树莓派 + 面包板（外设）              │ ← 灯带要露出
   │  ┌─────┐  ┌─────────────┐           │
   │  │ Pi  │  │ 面包板       │           │
   │  └─────┘  │ 灯带 / 继电器 │           │
   │           │ 舵机 / 传感器 │           │
   │           └─────────────┘           │
   └──────────────────────────────────────┘
```

把灯带摆成弯曲形状（U 形或 S 形），亮起来更有视觉冲击。

### 1.3 录制设置

- **分辨率**：1080p
- **帧率**：60fps（灯带颜色变化丝滑）
- **方向**：横屏
- **声音**：建议后期配解说，现场只录环境音
- **时长**：严格控制 ≤ 180 秒

### 镜头 3：场景一·"我准备睡觉了"（30-60 秒）

**画面**：
1. 在 Streamlit 输入框输入或语音说"我准备睡觉了"
2. 屏幕展示意图识别为 mode.sleep + 14 步规划
3. 点"确认"
4. **特写镜头切到硬件**：
   - 灯带从亮转暗（暖白 15%）
   - 风扇启动（看叶片）
   - 舵机转动（窗帘动作）
   - 继电器咔嗒（锁门音效）
   - 蜂鸣器短鸣（确认）

**字幕**：
```
场景：睡眠模式
意图：mode.sleep（置信 0.97）
规划：14 步动作链
延迟：< 30ms（端侧）
```

**解说**：
> 一句话触发 14 步家居动作。所有动作的规划、安全确认、执行
> 全部在树莓派上完成，端到端延迟 30 毫秒以内。

### 镜头 6：场景四·传感器闭环·煤气泄漏（95-130 秒）⭐ 重头戏

3. **画面切到硬件**：

**解说**（重点：这段语速放慢、声音洪亮）：
> 这是真实的传感器闭环。当燃气传感器检测到危险值，

## 三、录制小技巧

### 3.1 拍硬件特写

- 用手机微距模式，靠近灯带 5cm
- 灯带亮起来用慢动作（240fps）拍 3 秒，剪片时放 2 倍慢
- 舵机转动可以用侧拍，能清楚看到角度变化

### 3.2 屏幕画面录制

笔记本上单独录屏：
- Windows：用 OBS Studio（免费）或 Win+G 自带工具
- 录制时关闭通知，关闭微信/QQ
- 字体调大到 110-125% 让观众看清楚

### 3.3 后期剪辑

工具推荐：剪映（手机 / Windows 都有，免费）
1. 把硬件镜头 + 屏幕镜头剪在一起
2. 添加字幕（用剪映自动识别）
3. 配解说音（自己录或用 AI 配音如剪映"云阶"音色）
4. 转场用"叠化"或"白光闪过"，避免硬切
5. 背景轻音乐（剪映免费音乐库），音量 -20dB

### 3.4 时长控制

如果剪完超过 3 分钟：
- 优先压缩镜头 1（硬件全景缩到 8 秒）
- 镜头 2（架构讲解缩到 10 秒）
- 镜头 6（煤气泄漏） **不要压**，这是最值钱的

## 四、常见拍摄问题

| 问题 | 解决 |
| --- | --- |
| 灯带颜色饱和度过高，曝光过曝 | 手机调降低曝光补偿 -1.0 |
| 画面有交流电频闪 | 关掉日光灯，用台灯 |
| 解说背景噪音大 | 用手机录解说+剪映降噪；或换安静房间重录 |
| 屏幕反光 | 调整笔记本角度，避开光源；或贴磨砂膜 |
| 镜头抖 | 上三脚架；或用相机包/书垫稳手机 |
| 时长超 5 分钟 | 砍掉镜头 4（中文数字）；保留 1/3/6/8/9 |
